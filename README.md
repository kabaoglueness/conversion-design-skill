# Conversion Design Skill 🎯

> **Zero AI Slop. Ruthless Conversion Engineering & Visual Hierarchy for AI-Built Web Applications.**

Yapay zeka modellerinin ürettiği ruhsuz, dağınık, mor gradient'larla boğulmuş ve dönüşüm sağlamayan web arayüzlerini engelleyen; kurumsal kimlik, Gestalt boşluk disiplini ve satış odaklı hiyerarşi kurallarını tavizsiz işleten Antigravity / Gemini CLI becerisi (skill).

---

## ⚡ Özellikler ve Standartlar

- **Sıfır Yağlama / Dürüst Refleks:** Yapay zeka tasarımda veya akışta dönüşümü düşürecek bir hata gördüğünde kullanıcıya içi boş iltifatlar dizmez; doğrudan teknik gerçeği ve çözümü söyler.
- **Viewport Başına Tek Primary CTA:** Ekranda dikkat dağıtan yarışan renkli butonları yasaklar; tek birincil eylem ve altına risk kırıcı mikro-güvenceler yerleştirir.
- **60-30-10 Renk Disiplini:** Markanın aksiyon rengini (%10) sadece dönüşüm butonlarına saklar.
- **Sürtünmesiz Form & E-Ticaret:** Misafir alışverişi zorunluluğu, anlık (onBlur) doğrulama, mobil klavye ergonomisi ve gizli masraf yasağı.
- **Dashboard Veri Ergonomisi:** Normal metrikler nötr tonlarda kalırken, sadece eylem gerektiren anomaliler vurgulanır. Sayısal veriler daima sağa yaslanır (`tabular-nums font-mono`).
- **10 Kapılı Otonom Denetim (Self-Audit Linter):** Kod ve arayüz teslim edilmeden önce 10 maddelik dönüşüm kontrolünden geçer.

## 🚀 Kurulum (Installation)

### 1. Antigravity & Gemini CLI (Global)
Bu repodaki `SKILL.md` dosyasını global skill dizinine kopyalamanız yeterlidir:

```bash
# Windows (PowerShell)
Copy-Item .\SKILL.md "$env:USERPROFILE\.gemini\config\skills\conversion-design\SKILL.md"

# Linux / macOS
mkdir -p ~/.gemini/config/skills/conversion-design
cp SKILL.md ~/.gemini/config/skills/conversion-design/
```

### 2. Proje Bazlı (Yerel Workspace)
Projenizin kök dizininde `skills/conversion-design/SKILL.md` yoluna ekleyebilirsiniz.
